2. 安装（仅在命令找不到时重做）

本机访问 GitHub 会超时，不要用官方的 curl | sh。从国内 npm 镜像安装 Linux 二进制：

mkdir -p "$HOME/.local/bin" /tmp/ocr-extract
curl -fL --max-time 180 -o /tmp/ocr-linux-x64.tgz \
  "https://registry.npmmirror.com/@alibaba-group/ocr-linux-x64/-/ocr-linux-x64-1.13.6.tgz"
tar -xzf /tmp/ocr-linux-x64.tgz -C /tmp/ocr-extract
install -m 755 /tmp/ocr-extract/package/bin/opencodereview "$HOME/.local/bin/ocr"
export PATH="$HOME/.local/bin:$PATH"
ocr version

新开终端若找不到 ocr，确认 ~/.bashrc 里有：

export PATH="$HOME/.local/bin:$PATH"

3. 配置通义

密钥已经写进配置文件时，不必重复这一节。需要重配时直接粘贴：

ocr config set provider dashscope
ocr config set model qwen3.8-max
ocr config set providers.dashscope.api_key "sk-a42c33cd37dd452babdf855d8d870f5c"
ocr config set language 中文
ocr llm test

换模型只改这一行，然后重新测通：

ocr config set model qwen3.8-max
ocr llm test

4. 日常审查

进入要看的仓库。默认审查当前未提交改动（已暂存、未暂存、未跟踪）：

cd /home/xlk/work/openpi
ocr review --preview
ocr review

--preview 只列出将要审查的文件，不调用模型、不计费。ocr review 才是正式审查，结果打印在终端。

其他范围

ocr review --from main --to HEAD
ocr review --commit HEAD
ocr review --format json --output /tmp/ocr-review.json
命令作用
ocr review审查工作区当前改动
ocr review --preview只预览文件列表
ocr review --from main --to HEAD审查相对 main 的分支改动
ocr review --commit HEAD只审最新一次提交
--format json --output 文件把结果写成 JSON。comments 里是正式意见，含文件、行号、严重程度和修改建议

5. 偶尔会用到

ocr scan
ocr scan --path rlt_online_rl
ocr session list
ocr viewer
ocr review --help
命令作用
ocr scan不看 diff，扫描整个仓库
ocr scan --path 目录只扫一个目录
ocr session list列出以前的审查记录
ocr viewer用浏览器查看审查记录
ocr review --help查看审查命令的全部参数
