结论

  1. 螺丝任务上的 RL 是细调。actor 被模仿项拴在参考动作上，探索标准差是 0.002。它比较的是策略自己已经做成过的邻近轨迹，把更早插入的那条排到前面。
  2. 人手的作用是把恢复动作写进策略。同一种对歪，第一次记失败；再出现时接手到插入。人手步模仿实际执行的抬起、对准、插入。策略自己走出的步仍模仿 VLA 参考。曲线只看零人手步的成功。
  3. critic 往后看的动作是目标策略在下一状态的输出，不是样本里人手的下一步。策略还不会在接手点抬起时，对歪段的目标接近 0。学会之后，这段目标变成恢复路径的折扣价值，约 0.770。
  4. Q 权重在 30000 次更新后已经从 0 变为 1.0。在出现零人手成功、并且这些成功的 Q 不再是一条平线之前，再加大 Q 权重不会把对歪的动作拉开。
  5. 本次代码改的是记录与真实发送一致：过期计划不再发出，晚按的成功留在最后一拍真实动作上，全零关节目标按走到 0 来学习。训练损失和「下一步用目标策略」没有改。

1. 正确的训练方法

分两段。第一段让策略在曾经对歪的状态上自己做出恢复。第二段在已经能自己插进的轨迹里，用折扣比较谁更早完成。

采集规则

这条规则在操作，不在损失里。代码不能从「每次都救到插入并记成功」里变出稳定提升。

  • 同一种对歪第一次出现：不接手，记失败。这一条的回报属于策略自己的 v。
  • 同一种对歪再次出现：接手，直到插入，记成功。人手步成为恢复动作的模仿样本。
  • 对外只报告零人手步的成功次数和这些成功完成的步数。人手插到底再按成功，用来训练恢复，不记成策略变好。

第二段比较什么

30000 次之后 Q 权重已经是 1.0，不必再加大。噪声保持 fixed_std: 0.002。只有零人手成功出现，并且这些成功之间的 Q 不再是常数，actor 才会沿斜率离开模仿目标。比较的量是折扣后的完成时刻，计算在下一节。

2. 同一条轨迹上的计算

40 个控制步，4 块，每块 10 步。块 0 是策略，钉子对歪。块 1 是人，抬起并对准。块 2、块 3 松开后由策略完成，第 39 步插入，该步奖励为 1，回合在块 3 结束。这个例子用来看备份；真实采集里，人经常一直插到成功，第 1 落到人手那一拍，见本节后半。

折扣

时间常数设成 5 秒。30 Hz 下是 150 个控制步。

γ = 1 − 1 / (30 × 5) = 1 − 1/150 = 0.993333
def resolve_credit_gamma(*, gamma, control_frequency_hz, credit_horizon_sec):
    steps = control_frequency_hz * credit_horizon_sec
    return 1.0 - 1.0 / steps

表 1. 0.993333ⁿ，保留四位。此前口头使用的 0.942、0.881、0.824、0.770、0.875 是这些值的三位近似。

策略还不会抬起

块 3 含有奖励 1 且 done = 1，目标就是 γ⁹ × 1 = 0.9416。被打分的动作是块 3 里存下来的那 10 步。

块 0 的 10 步奖励都是 0，done = 0，目标是 γ¹⁰ Q(s₁, π(s₁))。s₁ 是接手时的状态。π(s₁) 若仍输出对歪的 v，而 v 到不了插入，这个 Q 接近 0，块 0 的目标就是 0。人手在 s₁ 之后实际抬起来了，这件事不写入块 0 的自举，因为自举读的是 π(s₁)，不是样本里的 h。

策略已经会在接手点抬起

模仿把 h 学进 π(s₁) 之后，从 s₁ 出发的策略自己能走到第 39 步的 1。块 0 的目标变成：

γ¹⁰ × γ²⁹ = γ³⁹ = 0.7704

0.7704 是「从对歪之后的状态继续，策略自己能插进」的折扣值。它出现的条件是策略自己会恢复。在那之前块 0 仍接近 0。

块存下来的动作 还不会恢复 已经会恢复

1 步 10–19人手 h取决于后面的 π0.8237
2 步 20–29策略0.88070.8807

表 2. 四块各自对齐、奖励只在第 39 步、只在块 3 结束时的目标。块 2 的 0.8807 = γ¹⁰ × 0.9416。块 1 的 0.8237 = γ¹⁰ × 0.8807。

人一直插到成功时，1 落在 h 那一拍，critic 学到的是接手状态上 h 的价值。例如 1 在某人手块的最后一拍且该块结束回合，这条人手动作的目标是 0.9416。这是吸收，不是把人手的下一步写进策略块的自举。

同一个窗口里既有 v 又有 h

本次没有在接手处把窗口切开。一步轨迹的奖励向量若同时盖住策略步和人手步，并且 1 落在这个窗口里，done = 1 会去掉自举，奖励和里已经有这个 1。接收这个目标的动作向量包含对歪的前缀。这是换手落在同一条存储样本里时的赋值。采集上用「第一次对歪记失败」把策略自己的失败回报留下来；窗口本身仍按执行过的连续步来切。

更早插入值多少

两条都是零人手的成功。一条在第 39 步得到 1，从起点看是 0.7704。另一条在第 20 步得到 1，是 0.8748。差值 0.1044 就是第二段要比较的量。actor 只会在自己采样到的邻近轨迹上看到这个差。

3. Q 只能做局部挪动

在线阶段 actor 的损失是模仿惩罚减 Q。模仿对块内所有维求和，再对 batch 取平均。Q 是每条样本一个标量，同样对 batch 取平均。

L = 1.5 · mean Σᵢ (μᵢ − ãᵢ)² − 1.0 · mean Q(s, μ)

对第 i 维令导数为 0。求和里只有含 μᵢ 的那一项给出 2(μᵢ − ãᵢ)，batch 平均在两边同时出现，约掉。

μᵢ − ãᵢ = (∂Q/∂μᵢ) / (2 × 1.5) = (∂Q/∂μᵢ) / 3

ãᵢ 在策略步上是 v，在成功接手的人手步上是 h。∂Q/∂μᵢ 在 v 附近为 0 时，右边是 0，μᵢ 停在 v。把 Q 权重从 1 再加大，只改变分母里的系数；斜率为 0 时位移仍是 0。

fixed_std: 0.002 是 actor 在归一化动作上的高斯标准差。采样留在当前输出旁边。从对歪跳到先抬起再对准，超出这团噪声。Q 在 h 上等于 0.94，只说明接手状态配 h 值高，不会自动变成对歪状态上从 v 指向 h 的斜率。

斜率要由策略自己的样本产生：在对歪附近试到的动作，有的后来自己插进了，有的没有，或者插入的步数不同。试到之后，μ 沿斜率离开 ã，每一维大约移动斜率的三分之一。移动改的是已经能插进的轨迹，例如少绕一点、早几拍接触。

因此以前成功率不涨，和「RL 没有比较差异」是同一件事。当时记成成功的回合是人插到底的。自主插入接近零，对歪段的 Q 是平的，30000 次之后把 Q 权重打开，actor 仍停在 v。

4. 这次落地的采集修正

下面五处保证学习用的动作就是发出去的动作。它们不改变第 2 节的备份公式，也不改变两段训练的顺序。提交 51c3656。

4.1 推理期间接手，旧动作发不出去

每次开关策略、显式设置控制权、回合复位，控制版本加一。本拍开始时记下版本。真正发送在同一把锁里核对：回合还在、策略仍开着、版本没变、不在恢复冷却里，才调用发送。

def dispatch_policy_action(self, expected_epoch, command):
    with self._lock:
        if (not self._episode_active or not self._policy_enabled
            or self._control_epoch != int(expected_epoch)
            or time.time() < self._resume_until):
            return False, None
        return True, command()

4.2 旧后缀和 RTC 队列一起作废

下一拍发现版本变了，当前计划清空，RTC 队列作废，这一整段标 drop_transition，回放在这里断开。版本变化包括「关了又开」：布尔值回到开，版本已经不同，旧的 P1 不会接着发。

def _ownership_changed(self):
    policy_epoch = self._intervention_state.policy_epoch()
    previous_epoch = self._last_control_epoch
    self._tick_policy_epoch = policy_epoch
    if previous_epoch == policy_epoch:
        return False
    self._last_control_epoch = policy_epoch
    if self._rtc is not None:
        self._rtc.note_policy_enabled(False)
    return previous_epoch is not None

6. 怎样看一轮是否走在这条路上

  1. 日志里分开数零人手成功和有人手步的成功。只有前者用来判断策略是否变好。
  2. 第一段期间，成功接手的人手步模仿误差应下降。失败接手不应被模仿。策略步仍贴近 v。
  3. 零人手成功还是 0 时，Q 大致是平的，actor 相对 v 的偏差接近 0。这时保持 online_q_weight = 1.0。
  4. 零人手成功出现之后，看这些成功的完成步数和对应 Q。更早插入的样本 Q 应更高，量级上第 20 步相对第 39 步大约高 0.10。actor 相对 v 出现小的、方向一致的偏差，偏差约是斜率的三分之一。
  5. 若零人手成功长期为 0，先增加「同一种对歪第二次才接手」的恢复样本，而不是加大 Q 权重或探索标准差。基础轨迹加上被模仿吸收的恢复，还没有产生可比较的回报差。

本次没有改的部分：不把接手标成回合结束，不把成功奖励从插入那一拍拿掉，不把策略步的模仿目标从 v 改成执行动作，不在接手处拆窗口，不把 chunk_len 改成 1，不把探索标准差改成 0.05。这些会改变现在这条「先模仿恢复、再局部比较」的路径。
